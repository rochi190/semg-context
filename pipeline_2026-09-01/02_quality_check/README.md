## ★ plot_signal.py — 訊號品質（本專案目前最重要的把關）

```bash
PYTHONPATH=src python -m semg.v2.plot_signal 某份錄音.csv
# 或在 V5moving/ 裡：python run_qc.py 某份錄音.csv
```

輸出**兩張圖**（判定共用同一套指標）：

| 檔案 | 畫什麼 | 用途 |
|---|---|---|
| `_qc.png` | RMS 包絡線（40 Hz） | 自己快速篩檔 |
| `_qc_wave.png` | 濾波後**原始波形**（2000 Hz） | 給別人看 —— 跟特徵計算同一個域 |

### 六項指標

| 指標 | 定義 | 抓什麼 |
|---|---|---|
| `clip` | `|counts| ≥ 0.98 × 2²³` 的比例 | ADC 撞滿刻度 |
| `flat` | 連續 ≥25 ms 數值完全不變的比例 | 線斷、ADC 卡住 |
| `noise` | RMS 包絡的 p10（基線） | 底噪過高 |
| `dyn` | p95 / p10 | 有沒有調變（整份平坦 = 沒接到肌肉） |
| **`f60`** | 60±2 Hz 功率佔 20–450 Hz 的比例（**陷波前**） | ★ 電極接觸阻抗 |
| `art` | 突波段落佔全長比例 | 動作假影、拉到導線 |

### ★ 為什麼 60 Hz 是最有用的一項

在既有 7 份錄音上，陷波**前**的 60 Hz 佔比與該份的 LORO 準確率：

$$r = -0.942\ (p = 0.001)$$

```
17-23-12   4.4%  → 98.1%          16-26-55  27.6%  → 87.8%
17-11-49   4.7%  → 97.4%          14-56-09  42.5%  → 67.9%
```

⚠️ **但因果不是「60 Hz 害的」** —— 陷波器把它壓到 1.3~1.8%，
殘餘量與準確率就**不相關**了（r = −0.166, p = 0.72）。
它是**電極接觸阻抗的代理指標**：接觸差 → 市電耦合更多、同時 EMG 更弱。
真正進到訓練資料的是諧波（120/180/240 Hz，陷波器**不會**濾掉，r = −0.849）
與變差的訊噪比。

→ **看到 f60 高，該做的是重貼電極，不是加更多濾波器。**

### 兩個刻意的設計

**① 這裡關掉 Hampel。** Hampel 的工作就是把突波換成鄰域中位數 ——
診斷電極時那正好是要看的東西。開著找突波等於戴手套摸東西。

**② 縱軸上限固定、超標時標出來。** 一次飽和突波（可到 534 mV）
會讓自適應縮放把整條肌電壓成平線。但靜靜地裁掉也不行 ——
壞通道會看起來跟正常的一樣。所以超標比例直接寫進 y 軸標籤。

### ⚠️ 一個代價很大的錯誤（已修）

早期用 `|x| > 50 mV` 判定「飽和」。電極的直流半電池電位正常就到數十 mV，
所以那個指標量到的是**直流偏壓**，不是飽和。後果：把一條好通道判成
「整份 550 秒全壞」，並據此設計了兩組不必要的實驗。

**正確做法**：飽和在 **counts** 域比 `2²³`；肌電振幅在**帶通後**的域量；
直流偏壓單獨報告，不當故障指標。

★ 教訓：**指標必須在它有意義的域上定義。** 在錯誤的域上算出來的指標
不會報錯，只會給出有說服力的錯誤答案。

## audit_trials.py — 動作有沒有做錯

```bash
PYTHONPATH=src python -m semg.v2.audit_trials 某份錄音.csv
```

錄製時受試者無法全程專注，而且**來不及記下哪一次做錯**（下個 cue 馬上來）。
第一份真實錄音 40 個 trial 裡就有 4 個做錯。

⚠️ **dropout 解決不了這件事** —— dropout 是防特徵共適應的正則化，不是防標籤雜訊。
每個姿勢只有 5 次重複，錯 1 次 = 該姿勢 20% 的訓練資料是錯的，
那是**系統性**錯誤，模型會確實地學進去。

### 三個獨立準則

1. **姿勢做錯**（leave-one-trial-out 交叉預測）
   對每個 trial，用**其他所有 trial** 訓練 RandomForest（沒看過它），
   再預測它的 `go` 段。穩定被判成別的狀態 → 訊號與 cue 標籤不符。
   ★ 逐 DOF 做，不是對整體姿勢做 —— 實測整體比對在第一份錄音上給了
   2 個誤報，逐 DOF 診斷顯示那兩個三個部位全部相符。
2. **rest 沒回到基線** —— 以開頭空白段為絕對基線，檢查 rest 段是否還在高活動。
3. **反應太慢** —— 量 prepare 起點到訊號到達高原的時間。

### ★ 稽核範圍必須限定在同一次錄音內

參考基準是「這個姿勢長什麼樣」，而那**取決於電極位置**。
跨錄音比對會把「電極貼法不同」誤判成「動作做錯」。
