# 03 — preprocess：濾波與標籤

三個檔案，兩件事：**把訊號弄乾淨**（`preprocess.py`）、**知道每個時刻是什麼姿勢**
（`cues.py` + `labeling.py`）。

---

## preprocess.py — 濾波

### 訊號鏈

```
counts → mV：  x[n] = counts[n] × 6.7055e-5
      ↓
60 Hz 陷波：   IIR notch，Q = 30 → 帶寬 60/30 = 2 Hz
      ↓
20–450 Hz 帶通：Butterworth 4 階
      ↓
（可選）Hampel：滑動中位數，半寬 100（±50 ms），γ = 2.0    ← 交付模型是關的
```

### 為什麼陷波 Q = 30

帶寬要夠窄才不會把 60 Hz 附近的肌電一起挖掉。sEMG 主要能量在 20–150 Hz，
60 Hz 正好在**中間** —— 最不利的位置。2 Hz 的凹陷只移除約 2/430 ≈ 0.5% 的通帶。

⚠️ **陷波器濾不掉諧波。** 120/180/240 Hz 全部落在通帶內，原封不動進入特徵。
實測諧波含量與準確率相關 r = −0.849。

### 為什麼帶通是 20–450 Hz

- **下限 20 Hz**：移除運動假影（0–20 Hz）、直流偏壓（電極半電池電位，可達數十 mV）、
  心電汙染的低頻成分（ch1 貼在軀幹，必然收到心電）
- **上限 450 Hz**：sEMG 能量 99% 在此以下，且低於 Nyquist 1000 Hz

### ★ 為什麼用因果濾波（`lfilter`）而不是零相位（`filtfilt`）

`filtfilt` 前向+後向各濾一次，相位失真為零 —— 但它**需要看到未來的樣本**。
即時系統做不到。

如果訓練用 `filtfilt`、部署用 `lfilter`，模型看到的輸入分布就不一樣。
這是**靜默的**訓練/部署不一致：不會報錯，只會讓實機表現比離線數字差。

**本專案的做法**：訓練、離線評估、即時部署**全部**走同一個 `StreamFilter`
（因果 `lfilter` + 狀態保留）。連離線畫圖的 `predict_and_plot.py` 也是重播串流。

### 關於 Hampel

$$m[n] = \text{median}(x[n-K:n+K]),\quad \sigma[n] = 1.4826 \cdot \text{MAD}[n]$$
$$y[n] = m[n] \text{ 若 } |x[n]-m[n]| > 2\sigma[n],\ \text{否則 } x[n]$$

（1.4826 = 1/Φ⁻¹(0.75)，使 MAD 在高斯下成為 σ 的一致估計量。）

| | Hampel 開 | Hampel 關 |
|---|---|---|
| 每視窗計算 | 19.4 ms | **6.55 ms** |
| 濾波器本身 | 14.12 ms（**佔 77%**） | 0.10 ms |
| 準確率（3 種子 × 7 折） | 基準 | −0.13% ± 6.33%，**p = 0.926** |

**分不出差異，但佔 77% 的計算** → 交付模型全部關掉。

⚠️ 開/關**必須重新訓練** —— 換濾波器等於換輸入分布，舊 scaler 與權重全失效。
這個設定寫進模型 bundle，載入時照 bundle 的值建濾波器。

## cues.py — cue 檔 → 標籤區間

把 `_cues.csv` 的事件轉成 `[start, end)` 樣本區間，並套上 margin。

### ★ 三個 margin 值不同，因為吸收的東西不同

| margin | 值 | 吸收什麼 |
|---|---|---|
| `go` 起始 | 0.5 s | 受試者還在微調姿勢，變異大 |
| **`rest` 起始** | **1.0 s** | ★ 肌肉還在**放鬆** —— 生理衰減，比擺姿勢慢得多 |
| 結束 | 0.2 s | 提前放鬆，通常很短 |

`rest` 特別長的依據：實測從 `return` 起點衰減 90% 需要 p90 **2.86 s**、max **3.65 s**。
協定的衰減預算是 `return(2.5) + rest起始margin(1.0) = 3.5 s`，覆蓋 98%。

### `prepare` / `return` 段標成 −1

移動過程不屬於任何穩定狀態，標成 −1，訓練時用 `ignore_index=-1` 跳過。
沒有這個機制，移動過程會被強制標成某個狀態，模型學到的邊界就是錯的。

### ★ 校準區間重定位（一個已修的坑）

即時推論啟動時要在開頭的空白段算每通道的穩健尺度。
但如果那段落在 `_badspans` 裡（訊號壞掉），尺度會被膨脹 —— 實測 30×/74×。

修法：`calibration_span()` 自動改用**最長的乾淨休息段**（≥1.5 s）。

⚠️ 第一版的修法要求長度 ≥3.5 s，結果把每一個 release 段都濾掉了。
⚠️ 另一個相關的坑：離線評估時「從校準結束才開始預測」——
校準若被搬到 541 s，550 s 的錄音只評估了 5.5 s，卻報出看似合理的數字。
修法：校準後 `reset_stream()`，從頭重播。

## labeling.py — 自動標籤

從包絡線推導 gesture + phase，**不需要 trial 時間戳**。

⚠️ 門檻用**百分位數**而非 `median + K·MAD`。
實測 `median + 3·MAD` 在 8/28 個檔案上完全失效（門檻算出來比 p95 還高），
原因是那個公式假設「大部分時間在休息」；活動佔比高或分布寬時
median 會落進活動區、MAD 也跟著膨脹。百分位數對活動佔比不敏感。
