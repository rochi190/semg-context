# 一頁摘要

## 1. 這個系統做什麼

前臂與上臂共 7 通道表面肌電（sEMG），即時解碼出**三個自由度同時**的姿勢，
用來驅動機械手臂（uFactory Lite 6，作為手部外骨骼的早期致動器代理）。

```
        手部 hand      {rest, index, thumb, pinch}    4 態
        手肘 elbow     {rest, flex}                   2 態
        肩膀 shoulder  {rest, flex}                   2 態
                                    → 理論組合 4×2×2 = 16 種
```

★ **關鍵設計決定：多輸出，不是單一 16 類。**
單一互斥分類（大部分論文的做法）沒辦法表達「同時維持多個姿勢」，
而且要湊滿 16 類的訓練資料。多輸出三個頭各自預測，
理論上可以組合出沒訓練過的姿態 —— 這件事後來成為整個專案最大的技術爭點（見 §4）。

## 2. 訊號到決策的完整路徑

```
ADS1299 (2000 Hz, 24-bit, gain 8)
  → mV 轉換           x[n] = counts × 6.7055e-5
  → 60 Hz 陷波         IIR notch, Q = 30
  → 20–450 Hz 帶通     Butterworth 4 階，因果（lfilter，不是 filtfilt）
  → 切窗               500 ms 視窗 / 50 ms 步進（90% 重疊）
  → 特徵               每視窗 120 維（105 逐通道 + 15 跨通道）
  → 標準化             StandardScaler（訓練集統計量，存進模型檔）
  → 序列               10 個視窗 = 0.95 s 的時間脈絡
  → 神經網路           SplitMultiHead，16,954 參數
  → 逐自由度投票        5 票多數決 + 遲滯
  → 控制層             三道去彈跳閘 + 最小維持時間
  → Lite 6
```

**延遲預算 1.15 s** ＝ 視窗 0.5 + 序列 0.45 + 投票 0.20。
每視窗計算 **6.55 ms**（預算 50 ms，餘裕 87%）。

## 4. 兩個值得在會議上講的發現

### (a) 共享表示層讓多輸出退化成「背組合」

多輸出架構理論上能組合出沒見過的姿態，但實測**不行**：
使用者舉手肘 + 彎食指時，手部頭完全不觸發。

診斷：訓練資料只涵蓋 9 種組合（不是 16 種），共享的 backbone
把「哪些自由度會同時出現」一起學進了表示層。

決定性實驗（留一組合測試：訓練時**排除** pinch+彎肘，測模型能不能自己組合）：

| 特徵子集 | hand | elbow | shoulder |
|---|---|---|---|
| 全部 120 維 | 66.7% | **29.9%** | 93.7% |
| 只有近端 66 維 | 0.0% | **91.8%** | 97.5% |
| 只有遠端 51 維 | **89.1%** | 0.5% | 52.7% |

手肘只看近端通道時 29.9% → **91.8%**。
**另一組的特徵不是沒幫助，是在主動干擾。**

→ 改成 `SplitMultiHead`（每組通道各自獨立的編碼器），
留一組合測試從 **5.0% ± 2.0% → 85.4% ± 1.9%**（3 種子，p = 0.0008）。

### (b) 一直在用的評估指標系統性高估 22 個百分點

同一次貼片錄的兩份錄音共用電極位置、阻抗、皮膚狀態。
「留一份錄音」把其中一份留出來測試時，**它的同場次雙胞胎還在訓練集裡** ——
模型只要認出那組電極的長相就能答對，不需要真的學會姿勢。

改成「留一貼片場次」（同一人同一天的錄音整組留出）：**95.3% → 73.0%**。

佐證：舊清單裡 `14-56-09` 是唯一沒有同場次雙胞胎的錄音，
它的「留一份錄音」分數就掉到 67.9%，而有雙胞胎的都在 87~98%。

## 5. 目前最大的瓶頸

**電極貼附品質，不是模型。**

| 同一位受試者（gary） | 60 Hz 汙染 | 留一場次準確率 |
|---|---|---|
| 2026-08-11 那次貼片 | 4.4% / 4.7% | 87.7% / 88.5% |
| 2026-08-21 那次貼片 | 48.1% / 21.2% | 75.7% / 62.4% |

同一個人、同一間教室、同一組電極、同一套程式，**差 19 個百分點**。

60 Hz 市電汙染程度與準確率相關 **r = −0.942 (p = 0.001, n = 7)**。
它不是直接原因（陷波器已經濾掉了），而是**電極接觸阻抗的代理指標**。

→ 對策：錄音前先錄 30 秒跑品質檢查（本次新做的 `run_qc.py`），
　 七個通道 60 Hz 都在 10% 以下再開始正式錄。
